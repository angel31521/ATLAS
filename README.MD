# ATLAS

Este proyecto en desarrollo esta pensado para digitalizar y facilitar la gestion de listas y cursos dentro de las instituciones, permitiendo de esta manera acceder de forma rapida y versatil a informacion de los estudiantes desde dos roles principales:


# Coordinador

1) Creacion cursos

2) Gestion de docentes

3) Gestion de estudiantes


# Docente

1) Gestion de lista de cursos 

2) Accede a iformacion del estudiante

3) Marcado de asistencia

4) Marcado de notas y actividades realizadas


# ENDPOINTS 

* GET/inicio  =  inicio de la pagina

* GET/inicio/login?rol=  =  login, el mismo para ambos roles / el identifiador de cada rol se le añadira en el registro el cual sera diferente para cada uno

# Ideas

* Cuando el coordinador se registre, se le enviara un codigo de invitacion al correo, el cual le dara a sus docentes para que se unan a la institucion.

* El coordinador en su panel de administracion podra validar cuando un docente quiera unirse a la institucion y de esta forma aceptar o rechazar.
